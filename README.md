## Участники

Владелец открывает «Профиль → Ключи участников» и сохраняет выданную партию. Каждый ключ SGM предназначен одному человеку. Участник входит через свой аккаунт ChatGPT, вводит ключ, выбирает свободный ник и активирует его. Этот же ключ используется для повторного входа. Участники не могут выпускать новые ключи или просматривать проекты другого аккаунта.

Для самого первого владельца работает ранее выданный ключ SG1. Новая открытая регистрация без ключа участника закрыта.

## Как начать

1. Откройте рабочее приложение и войдите через ChatGPT.
2. После интро введите ранее выданный личный ключ.
3. Новый участник вводит ключ SGM и выбирает свободный ник. Сервер хранит только хеш ключа.
4. При первом входе владельца в 4.2 старые проекты будут перенесены в зашифрованное хранилище. Закройте старые вкладки перед этим переносом.
5. Для отчёта нажмите «Экспорт → PDF-отчёт». Для очистки — «Инструменты → Очистка».

Файлы и графы хранятся на текущем устройстве в браузере. Вход с другого устройства не переносит проекты автоматически: используйте экспорт и импорт проекта JSON. Перед очисткой данных браузера сохраняйте резервную копию.

## Локальный запуск исходников

Требуется Node.js 22.13 или новее. Исходники рассчитаны на Vinext и Cloudflare D1, используется официальный Sites starter.

1. Установите зависимости: `npm ci`.
2. Соберите приложение: `npm run build`.
3. Создайте локальные таблицы:
   `node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_wealthy_hellfire_club.sql`
4. Запустите `npm run dev` и откройте адрес из вывода.
5. Для штатной локальной тестовой личности откройте `/signin-with-chatgpt?return_to=/` на том же адресе. Она действует только на локальном компьютере в режиме разработки.

На публикации используются настоящая приватная граница Sites/ChatGPT и серверная D1. Не добавляйте обход проверки личности в серверный код. Подробности — AUTH-SETUP.md.
